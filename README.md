# Modèle de sites vitrines

Un seul moteur animé, une fiche par commerce. Exemples fictifs dans `clients/`.

## Créer un site
1. Copier une fiche de `clients/` et la renommer.
2. Changer le nom, les textes, les couleurs, les photos et les prix.
3. Lancer `python construire.py`.
4. Mettre en ligne la page générée avec le dossier `assets/` et ses photos.

## Options d'une fiche
- `portant` : vêtements sur cintres qui balancent.
- `collection.categories` : catalogue filtrable avec fenêtre de commande.
- `tailles`, `couleurs` : choix envoyés dans le message WhatsApp.
- `whatsapp`, `url`, `instagram` : coordonnées du commerce.
- `demo` : `false` retire la mention « Démo » et autorise Google.
